# Automations and SLAs

_Last updated: 2025-12-05_

## Automation rules

Automations run actions (assign, tag, reply with a macro, escalate) when a ticket matches
conditions.

- Starter: automations are not available.
- Growth: up to 50 active automation rules.
- Enterprise: unlimited automation rules.

Rules run within 60 seconds of the triggering event.

## SLA policies

SLA policies set first-response and resolution targets per priority. They are available
on Growth and Enterprise. SLA timers can count calendar time or only business hours,
which admins define per team.
